# Temizle çekirdeği — uygulama planı

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Birebir kopyaları, benzer kareleri ve kusurlu fotoğrafları yerinde (`_Ayiklananlar`'a taşıyarak)
ayıklayan, geri alınabilir Temizle akışı: çekirdek + komut satırı.

**Architecture:** `DuplicateKeeper` öncelik koşulunu dışarıdan alacak şekilde genelleşir. `Scanner`
`_Ayiklananlar` adlı klasörlere girmez. `CleanSession` taramayı ve planı yürütür. `Executor` yeniden
adlandırarak taşıyan bir mod ve bu modun Geri Al'ını kazanır. Komut satırına `--clean` eklenir.

**Tech Stack:** C# .NET 8, xUnit.

**Spec:** `docs/superpowers/specs/2026-11-07-temizle-design.md`

## Global Constraints

- Hiçbir dosya silinmez, hiçbir dosyanın üzerine yazılmaz.
- Taşıma yalnız aynı sürücüde, `File.Move` ile yapılır.
- Klasör adları: `_Ayiklananlar`, alt klasörler `Tekrarlar`, `Benzerler`, `Kusurlu`. Günlük:
  `_Ayiklananlar\_Gunluk\temizlik-yyyyMMdd-HHmmss.jsonl`.
- Mevcut `DuplicateKeeper.Choose(g, PlanOptions, chosen)` davranışı değişmez. Mevcut 257 test yeşil kalır.
- Commit mesajlarında Co-Authored-By satırı yok.

## Review Focus

1. Kök sürücü kökü (`E:\`) → göreli yol ve `_Ayiklananlar` yolu doğru kurulmalı (`Path.TrimEndingDirectorySeparator`).
2. Kopyanın kalanı başka kökte, ayıklanan bu kökte → ayıklanan kendi kökünün `_Ayiklananlar`'ına gider.
3. Taşıma sırasında kaynak kilitli → dosyaya özgü hata, iş sürer, günlükte `Failed`.
4. Geri Al'da kaynak yolunda yeni bir dosya belirmiş → dokunulmaz (Skipped).
5. Aynı plan içinde iki dosya aynı `_Ayiklananlar` hedefine düşer → ikincisine ` (2)`.

Görev 2–3'ün testleri 1, 2, 4 ve 5'i sabitler.
