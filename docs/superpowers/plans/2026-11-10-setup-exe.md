# Setup.exe Implementation Plan

> Yürütme: superpowers:executing-plans (satır içi; kullanıcı uzakta, "planlı işleri yap").

**Goal:** Inno Setup ile Türkçe/İngilizce Setup.exe; sağ tıkla klasör seçili açılış; CI'de sessiz kur/kaldır denemesi.

**Spec:** `docs/superpowers/specs/2026-11-10-setup-exe-design.md`

## Global Constraints

- Commit'lerde Claude ortak yazar satırı yok. `.superpowers/` git'e girmez.
- Uygulama internete bağlanmaz; ayar klasörü `%LOCALAPPDATA%\FotoDuzenleyici` yalnız kullanıcı "Evet" derse silinir.
- Mutex adı: `FotoDuzenleyici.Calisiyor` (yerel ve `Global\`).
- CLI exe adı: `fotoduzenle`.

## Review Focus

1. Klasör argümanı tırnaklı/sonunda `\` olan yol (`"D:\"` → Explorer `%1` sürücü kökü) — klasör olarak tanınmalı.
2. Seçili klasör varken "Son kullanılanlar → Aç" kendi çiftini açmalı, seçimi değil.
3. Kaldırmada sessiz modda soru sorulmamalı, ayarlar kalmalı.
4. PATH'ten kaldırma yalnız kendi girdisini silmeli, diğerlerini bozmamalı.
5. Tüm kullanıcılar kurulumu HKLM'e, kullanıcı kurulumu HKCU'ya yazmalı (HKA).

### Task 1: Açılış klasörü (ViewModels + App)

- `StartArgs.Folder(string[] args, Func<string,bool> isDir) : string?` — ilk `--` ile başlamayan, `isDir` true olan argüman; sondaki `"` kırpılır (Explorer `"D:\"` → `D:"` tuzağı).
- `HomeViewModel(AppSettings, string? selectedFolder = null)`: `SelectedFolder`, `HasSelectedFolder`, `ClearSelectedFolderCommand`, `OrganizeCardCommand`, `CleanCardCommand`; event `SelectedFolderCleared`.
- `ShellViewModel(Services, string? startFolder = null)`: ilk ana ekrana verir; akış başlayınca veya × ile unutur.
- Testler: `StartArgsTests`, `HomeSelectedFolderTests` (kart çiftleri, Aç değişmez, temizle), `ShellStartFolderTests`.
- XAML: şerit + kart düğmeleri yeni komutlara.

### Task 2: Mutex ve CLI adı

- `App.OnStartup` ve CLI başı: iki mutex (`FotoDuzenleyici.Calisiyor`, `Global\FotoDuzenleyici.Calisiyor`), süreç boyunca tutulur; `Global\` açılamazsa yok sayılır.
- CLI csproj `AssemblyName=fotoduzenle`; README'deki kullanım güncellenir.

### Task 3: Inno betiği + publish.ps1

- `installer/FotoDuzenleyici.iss` (UTF-8 BOM), `/DAppVersion=` ve `/DSourceDir=` ile.
- `publish.ps1`: zip (değişmez) + `dist\setup` (App ve Cli, `-p:PublishSingleFile=false`) + ISCC bulunursa Setup.

### Task 4: CI

- `build.yml`: `kurulum` işi (PR + main push): publish, sessiz kur, denetle, sessiz kaldır, denetle, yapıt.
- `release` işi: Inno yoksa choco; zip + Setup.exe yükle.
- Doğrulama: dalı gönder, PR aç, `kurulum` işinin yeşil olduğunu gör.

### Task 5: Belgeler

- README kurulum bölümü (SmartScreen notu), CHANGELOG [Yayınlanmamış], YOL_HARITASI satırı.
